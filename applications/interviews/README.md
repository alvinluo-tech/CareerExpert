# interviews/ — 面试准备与复盘

每场面试一个文件:`<公司>-<岗位>.md`(interview-prep skill 自动创建/维护)

## 文件结构

```markdown
---
company: 公司
role: 岗位
round: 一面 / 二面 / HR面 / onsite
date: 2026-09-10
interviewer: (如已知)
---

## 准备
- 高概率问题(技术/系统设计/行为/反问)
- STAR 故事映射(来自 star-bank)
- 简历自审预警(可能被深挖的 bullet)

## 复盘(面试后)
- 被问住的问题 → 回填 profile/ 素材卡与 star-bank
- 表现自评 / 模拟面试评分卡
- 下轮策略
```
