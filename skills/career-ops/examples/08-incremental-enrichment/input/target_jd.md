# 字节跳动 — 基础架构部 · 高并发流媒体与分布式中间件专家 (社招)

## 职位描述
负责字节跳动全球视频/音频与实时流数据流转核心基础设施的架构演进与性能攻坚。支撑海量实时流数据的极速接入、动态路由与跨机房低延迟分发。

## 核心职责
1. 主导字节跳动超大规模流式计算中间件与消息传输网关的架构设计与核心研发；
2. 针对超高并发、大吞吐网络传输场景，深入 Linux 内核网络栈与内存模型，实施网络 I/O 多路复用与零拷贝性能攻坚；
3. 建设毫秒级故障自动隔离、多租户流控与混沌容灾体系，保障全球基础设施 99.999% 高可用；
4. 探索下一代分布式实时数据流技术，积极沉淀开源生态与高影响力架构设计。

## 任职要求
1. 本科及以上学历，计算机或相关专业，4 年以上高性能服务器或中间件底层研发经验；
2. 深入精通 Go / C++ 语言底层并发模型、内存分配器机制与 GC 调优原理；
3. 具备深入的流式计算 (Streaming)、分布式消息队列 (Kafka/Pulsar) 或网络高性能协议栈 (eBPF/DPDK/QUIC) 实战落地经验；
4. 熟练掌握 Linux 内核零拷贝 (mmap/sendfile/splice)、环形缓冲区等高性能设计模式；
5. 有知名高星开源项目主导者、核心贡献者或头部互联网大厂基础架构经验者优先。
