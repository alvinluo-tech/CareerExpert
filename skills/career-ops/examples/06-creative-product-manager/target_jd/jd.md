# 目标岗位：TikTok / ByteDance — 海外电商支付与资金平台高级产品专家

## 职位描述 (Job Description)
- **Base**：上海 / 新加坡
- **部门**：TikTok E-Commerce · Global Payment & Financial Platform

### 岗位职责：
1. 主导 TikTok 全球电商业务在欧洲、东南亚及拉美市场的跨境支付中台架构规划，统筹本地收单、智能动态路由、多币种清结算系统的产品演进；
2. 针对跨国多通道支付复杂性，设计基于通道可用率、通道费率、卡组织 BIN 码及历史成功率的自适应动态路由调度系统，持续提升收银台转化率与支付成功率；
3. 协同风控、法务与合规团队，严格遵循国际合规监管（PCI-DSS、GDPR、PSD2/SCA、各国中央银行支付执照条例），控制 Chargeback 欺诈拒付率；
4. 深度洞察海外消费者结账行为习惯，推动 BNPL 先享后付、数字钱包（E-Wallet）及本地转账创新体验落地。

### 任职要求：
1. 本科及以上学历，计算机软件、信息系统或金融工程背景优先；
2. 4 年以上出海互联网、跨境电商或知名 FinTech 机构（如 Stripe, Adyen, PayPal, Shopee, Lazada）支付产品实战经验；
3. 具备千万级日交易流水（GMV）的复杂支付系统架构设计经验，有成功的支付成功率量化提升与手续费优化案例；
4. 具备母语级或流利的英文工作语言能力，能顺畅协同全球跨国团队与境外金融机构。
