# 职位描述
负责字节跳动核心业务（抖音/飞书/国际化）高并发后端架构的研发工作。

## 岗位职责
1. 负责大规模分布式微服务系统的架构设计、开发与线上稳定性维护；
2. 负责海量高并发高吞吐流量下的性能调优、缓存架构设计与数据库瓶颈治理；
3. 参与关键核心模块的技术攻关，探索前沿分布式系统与存储技术落地。

## 职位要求
1. 2026 届应届毕业生，计算机、软件工程等相关专业本科及以上学历；
2. 基础扎实，精通或熟练掌握 Go/C++/Java 等至少一门编程语言，深入理解常见数据结构与算法；
3. 深入理解计算机网络（TCP/IP、HTTP）、操作系统原理及 Linux 常用调试排障工具；
4. 熟悉常见分布式中间件（Redis、Kafka 等）及 MySQL 数据库原理与优化；
5. 有 ACM/ICPC、CCPC、数学建模等高水平竞赛获奖者，或在 GitHub 有高质量开源项目（如实现过 Raft/LSM-Tree 等分布式存储原型）者优先。
