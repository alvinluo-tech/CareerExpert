# 目标职位：OpenAI / 硅谷头部 AI 独角兽 — 资深 AI Agent 与大模型系统架构师

## 职位描述 (Job Description)
- **Base**：北京 / 硅谷 / 全球远程 (Remote)
- **团队**：Applied AI & Autonomous Agent Systems

### 岗位职责：
1. 负责前沿自主智能体（Autonomous Agents）架构设计与落地，推动多智能体协同、规划反思、工具交互（Tool Use / Function Calling）在真实工程场景的规模化应用；
2. 针对超长上下文多智能体交互的推理延迟与 GPU 显存墙瓶颈，主导分布式推理加速（Speculative Decoding、KV Cache 压缩、PagedAttention、动态 Batching）系统的深度性能调优；
3. 统筹轻量化模型蒸馏、微调与端侧高效部署流水线，平衡大模型推理吞吐、响应时延与算力成本；
4. 深度参与开源社区生态建设，主导底层 AI 系统工程与核心基础设施演进。

### 任职要求：
1. 计算机科学、人工智能或相关专业硕士及以上学历，国内外顶尖高校优先；
2. 4 年以上大规模机器学习、大语言模型（LLM）系统工程或分布式系统架构实战经验；
3. 在 LLM 推理加速（如 vLLM, TensorRT-LLM, SGLang）、Agent 编排框架设计或 Triton/CUDA 算子优化有突出实战战果；
4. 有知名开源 AI 项目主导经验（如 GitHub 10k+ Stars）或顶会高质量学术论文发表者优先。
