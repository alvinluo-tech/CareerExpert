# career-coach — 简历通盘掌握与答辩军师技能

> **核心使命**：  
> 做您最专业的技术导师与备战军师。不同于考官挑刺，`career-coach` 带着教学与辅导的心态，**帮助求职者彻底读懂、吃透自己简历上的每一个字、每一项技术选型与每一个量化指标**。  
> **核心铁律**：  
> **绝不只给生硬的标准答案！** 重点在于提供**扎实的底层原理准备建议、高段位思考模型与解题思路引导**，让求职者在面对真实面试官的连环深挖时胸有成竹、底气十足。

---

## 一、 适用场景与快捷指令

- 用户说：
  - “帮我分析简历上的技术弱点 / 看看面试官会怎么深挖我的项目”
  - “我想彻底搞懂我写在简历里的底层原理 / 怎么准备答辩”
  - “生成我的专属简历通盘掌握与复习手册”
- 用户输入原生 Slash 指令：
  `/career-coach`

---

## 二、 交互与执行三步走工作流

```text
[用户输入 /career-coach 或简历] 
       │
       ▼
【第 1 步：简历初检与软肋标记】──> 圈定高危量化指标 (如 18.5万QPS、零拷贝、降本40%)
       │
       ▼
【第 2 步：主动追问与代码深挖】──> 询问 GitHub 链接或本地工程路径 (触发 inspect_repo.py)
       │
       ▼
【第 3 步：组装四维通透体系】────> 涵盖：软肋排雷 + 原理补课 + 思考模型 + 连环追问
       │
       ▼
【第 4 步：编译 HTML 并唤醒浏览器】─> render_guide.py 编译自包含 HTML 并静默打开
```

### 第 1 步：简历扫描与软肋圈定 (Vulnerability Scan)
读取用户当前简历，逐段排查以下两类高危特征：
1. **大词缺乏工程细节**：写了“分布式微服务重构”、“提升性能 60%”，但未言明具体实现手段；
2. **高硬核指标易引爆追问**：写了“单机 18.5万 QPS”、“零拷贝”、“日均 4500 万流水”等资深考官必算账的数字。

### 第 2 步：主动追问与素材/代码索取 (Proactive Ingestion)
向用户发出主动追问，引导提供真实代码或上下文（严格遵循事实唯一来源原则）：
> 🤖 **Agent 话术规范**：  
> *“我在您的简历中关注到了【项目名称】。这是面试官深挖的兵家必争之地：*  
> *1. 请问是否有该项目的 **GitHub 仓库链接** 或本地电脑上的 **代码目录路径**？（我可以帮您扫描底层依赖、并发模型与压测用例）；*  
> *2. 如果没有现成代码，能否用一两句话告诉我，当时压测的机器配置、数据规模以及最大的性能瓶颈卡在哪里？*  
> *掌握这些细节后，我将为您生成一份真正契合代码真实细节的《通盘掌握指导手册》！”*

若用户提供了代码目录，立即调用确定性脚本：
```bash
python skills/career-ops/scripts/inspect_repo.py <代码路径> --out profile/projects/<项目名>.md
```

### 第 3 步：组织四维核心内容 (4-Pillar Content Generation)
根据简历与代码证据，生成结构化 JSON 数据（包含以下四大模块）：

1. **模块 1：经历软肋与考官潜台词诊断 (Vulnerabilities)**：
   - 指出哪些句子最容易被资深面试官盯上；
   - 揭秘面试官潜台词（如“QPS 是纯内存空跑还是带网络 I/O？消息体多大？”）。
2. **模块 2：硬核底层原理补课清单与准备建议 (Technical Grounding)**：
   - 提取硬核技术原理进行白话速记（如 Cache Line 伪共享原理、Linux 零拷贝系统调用、对象池 GC 治理）；
   - 列出必看排查工具命令与复习清单（`pprof`、`perf`、`tcpdump` 等）。
3. **模块 3：高段位架构师思考模型与答辩思路引导 (Mental Models)**：
   - **STAR-T 模型**：定边界 $\rightarrow$ 说权衡 (Trade-offs) $\rightarrow$ 提局限与演进路线；
   - **“盲区与未涉足领域”的高情商解法**：教求职者如何坦诚说明未在生产环境实测，但基于底层原理推导方案。
4. **模块 4：经典硬核连环追问深度解析 (Deep-Dive Q&A)**：
   - 针对标杆项目提供 3~5 组由浅入深的连环提问；
   - 每题拆解：**【考官意图】** + **【外行踩坑禁忌】** + **【高分逻辑参考】**。

### 第 4 步：编译精美 HTML 手册并自动唤起系统浏览器
运行确定性编译脚本，生成单文件自包含 HTML，并通过 `--open` 参数在默认浏览器中即刻弹出：
```bash
python skills/career-coach/scripts/render_guide.py <数据.json> \
  --out applications/coach/<候选人>-mastery-guide.html \
  --open
```
同时保存对应的 Markdown 副本 `applications/coach/<候选人>-mastery-guide.md` 便于 Git 留痕。

## 三、 与 `career-interview` 的自然联动

当求职者使用 `/career-interview` 准备模拟对练时，系统会自动检测 `applications/coach/` 下是否已有对应岗位的通透手册。若尚未生成，考官将友好引导：
> *“检测到您简历中包含硬核技术指标，建议先运行 `/career-coach` 生成专属《简历通透与答辩手册》，彻底武装底层思路后再进入压力面试实战；当然，如果您准备充分，我们也可以直接开始！”*
