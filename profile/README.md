# profile/ — 素材事实库(唯一事实来源)

> 规则:`AGENTS.md` 第 1 节。这里的一切是简历、求职信、面试回答可以声称的上限。
> 不在这里的经历 = 不存在于简历中,直到你补录并通过确认。

## 文件

- `master-resume.md` — 主简历:完整、不分岗位的全部经历(从你现有简历迁移+扩充)
- `projects/` — 项目卡:一个项目一个文件,格式见 `projects/_template.md`
- `work/` — 工作经历卡:一段经历一个文件(职责、量化结果、可讲细节)
- `star-bank.md` — STAR 故事库:8~12 个母题故事,按 archetype 组织

## 为什么是"卡片"而不是一份大简历

- 简历定制 = 从卡片库中**选材和重排**,而不是每次重新写作 → 事实不漂移
- 卡片里的"可讲细节"列,是面试深挖时的弹药,简历上不放
- 新项目只需加一张卡,所有岗位族的简历都能立即引用它

## 维护节奏

- 每完成一个项目/一段经历,趁记忆新鲜立即建卡(10 分钟)
- 每次面试后被深挖住的问题 → 回填到对应卡片"可讲细节"或 star-bank
