# CareerExpert — career-coach (简历通盘掌握与答辩军师) 设计规范

- **文档状态**: 已通过头脑风暴审核 (Validated Design Spec)
- **创建日期**: 2026-09-03
- **目标技能**: `skills/career-coach` (原生快捷指令 `/career-coach`)
- **核心定位**: 私人技术总监与简历深度导师，提供“简历软肋诊断、代码工程深挖、输出专属精美 HTML 通透复习手册”全套能力。

---

## 1. 核心背景与用户真实痛点

在求职过程中，求职者面临两大致命痛点：
1. **投递后无反馈**：简历表述松散、缺乏硬核指标支撑；
2. **AI 润色后不敢去面试（怕被问穿）**：AI 改写的战果数据高大上（如“18.5万 QPS”、“零拷贝”、“降本 40%”），但求职者对底层实现细节、压测环境或替代方案权衡缺乏准备，面对资深面试官的连环深挖极易穿帮社死。

现有的模拟面试 (`career-interview`) 偏向考场的压力测试（挑刺与打分），缺乏考前的**“耐心教学、代码深挖与系统性思路武装”**。
因此，需要设立独立的 **`career-coach`** 技能，以军师和教练的姿态，帮助用户把简历上的每一个字、每一个指标的技术深度读懂读透。

---

## 2. 交互流与输入输出契约

### 2.1 触发与用户会话流程 (Interactive Dialogue)
1. **会话触发**：用户输入 `/career-coach`，或自然语言唤起（如 *“帮我分析简历上的技术弱点”、“生成我的简历通透复习手册”*）；
2. **简历初检 (Scan)**：AI 扫描经历与标杆项目，识别出“大词无细节”或“高硬核指标易引发追问”的重点段落；
3. **主动追问与素材索取 (Proactive Ingestion)**：
   - 询问是否有代码仓库链接 (GitHub/GitLab) 或本地代码目录；
   - 若无代码，引导用户简述压测配置、核心瓶颈与选型原因；
4. **代码级工程探测 (Inspect Repo)**：若提供代码路径，自动触发 `inspect_repo.py` 扫描依赖、并发模型、内存复用与测试占比；
5. **手册编译与自动弹出**：调用确定性脚本 `scripts/render_guide.py` 编译生成自包含 HTML，并通过系统默认浏览器自动打开。

### 2.2 输入与输出文件契约
- **输入数据**：
  - `profile/master-resume.md` 或用户当前简历文件 (PDF/HTML/MD)
  - 目标岗位 JD (可选)
  - 代码库路径 (可选)
- **输出产物**：
  - `applications/coach/<候选人>-mastery-guide.html`：极具现代美感的专属自包含 HTML 复习手册（自动打开）
  - `applications/coach/<候选人>-mastery-guide.md`：结构化持久 Markdown 副本

## 3. 《简历通透与答辩全景指导手册》四维内容架构

手册严格杜绝“死记硬背的标准答案”，重点在于**准备建议、知识补课与思路引导**：

### 模块 1：简历“脆弱软肋”与面试官潜台词诊断 (Vulnerability & Subtext)
- **精准圈定**：标出容易被攻击的高危指标（如“18.5万 QPS”、“零拷贝”、“分库分表”）；
- **潜台词剖析**：揭秘资深考官背后的真实疑虑（“是空跑还是挂了网卡？消息体多大？是否开了刷盘？”）。

### 模块 2：硬核底层原理补课清单与准备建议 (Technical Grounding)
- **知识点白话速记**：
  - 伪共享 (False Sharing) 与 Cache Line 补齐；
  - Linux 零拷贝 (mmap/sendfile/splice) 与传统 4 次拷贝对比；
  - 对象复用池 (`sync.Pool`) 与年轻代 GC 停顿治理；
  - 分布式锁续期机制与死锁防御。
- **复习备考清单**：列出推荐排查命令（`pprof`、`perf`、`tcpdump`、`strace`）与关键技术考点。

### 模块 3：高段位解题思维框架与答题思路引导 (Mental Models)
- **STAR-T 答辩模型**：
  1. **定场景**：主动给出基准机器参数与 Payload 规格；
  2. **说权衡 (Trade-offs)**：讲透为什么放弃业界现有框架，牺牲了什么，换取了什么；
  3. **提局限与演进**：主动指出方案当前的不足与下一阶段演进路线，展现成熟 Leader 视野。
- **“盲区/未涉足领域”的高情商解法**：教用户如何坦诚说明未在生产验证，但基于底层原理推导技术方案。

### 模块 4：经典硬核连环追问全景拆解 (Deep-Dive Q&A)
- 针对标杆项目提供 3~5 个高频连环追问；
- 每题拆解：**【考官意图】** + **【外行踩坑禁忌】** + **【高分逻辑参考】**。

## 4. 工程与组件设计 (Engineering & Tools)

### 4.1 目录结构
```text
skills/career-coach/
├── SKILL.md                     # 技能定义、主动追问规范、四维手册生成逻辑与红线
├── templates/
│   └── guide-template.html      # 精美现代自包含 HTML 模板 (响应式排版、代码块高亮、折叠排雷卡片)
└── scripts/
    └── render_guide.py          # 确定性渲染脚本：组装 HTML、自动调用系统浏览器静默打开
```

### 4.2 脚本设计 (`scripts/render_guide.py`)
- 输入：`guide_data.json` 或标准 Markdown 数据块；
- 输出：自包含单一 HTML 文件，无任何外部网络 CSS/JS 依赖；
- 功能：
  - 支持参数 `--out <filepath>`；
  - 支持参数 `--open`：自动执行 `webbrowser.open(filepath)` 在默认浏览器中唤醒查看；
  - 支持 `-h` / `--help` 标准退出。

### 4.3 生态协同与安装注册
- **与 `career-interview` 协同**：面试官在开场前若发现无指导手册，友好提醒用户可运行 `/career-coach` 提前武装思路；
- **与 `career-ops` 协同**：复用 `scripts/inspect_repo.py` 提取的代码级证据；
- **跨平台安装**：在 `install.ps1` 中将 `career-coach` 注册为第 6 大原生技能并同步至全局。

## 5. 验收标准与测试验证

1. **功能完整性**：
   - 运行 `render_guide.py` 能成功生成包含四大模块的 HTML 文件；
   - 验证 `--open` 标志能正常调用浏览器打开；
2. **内容质量与红线守护**：
   - 生成的辅导内容严格契合用户的真实简历与代码证据，不脱离现实捏造经历；
   - 四维架构完备，包含思路引导而非纯答案；
3. **集成测试**：
   - 在 `tests/test_e2e_scenarios.py` 中增加对 `career-coach` 核心渲染流程的测试断言，确保 100% 通过。
